{% comment %} Cómo va una línea de salida: "3 vendidas · 1 devuelta · 2026-09-30 · 1 pendiente". Una sola pieza para que la boleta, el historial y la pantalla del resultado lo digan igual. "Devuelta" y no "regresó": así lo manejan en la empresa —en las boletas de papel le ponen "dev"—. Cada devolución lleva su fecha, porque eso es lo que el papel no guardaba: solo se sabía que había regresado, no cuándo. Si una línea se devolvió por partes, cada parte sale con la suya. Quién la trajo va en el título, al pasarle el ratón encima. Recibe `salida`, el MovimientoVenta de la línea. En lo que no es una salida —un ingreso, una línea de Bodega Técnica, la propia devolución—, una raya. {% endcomment %} {% if salida.es_salida %}{% if salida.cantidad_vendida %}{{ salida.cantidad_vendida }} vendida{{ salida.cantidad_vendida|pluralize }} {% endif %}{% for devolucion in salida.devoluciones_por_fecha %}{{ devolucion.cantidad }} devuelta{{ devolucion.cantidad|pluralize }} · {{ devolucion.fecha|date:"DATE_FORMAT" }} {% endfor %}{% if salida.pendientes %}{{ salida.pendientes }} pendiente{{ salida.pendientes|pluralize }}{% endif %}{% else %}—{% endif %}
